¿Cómo obtengo el Client ID? (registro único, lo hace TI o un administrador — 5 min)
  1. Entrar a portal.azure.com → Microsoft Entra ID → Registros de aplicaciones → Nuevo registro.
  2. Nombre: Dashboard KPI Planner. Tipo de cuenta: solo este directorio organizativo.
  3. En URI de redirección elegir Aplicación de página única (SPA) y pegar la URL donde vive esta página (por ejemplo https://paolamp91.github.io/finanzas/planner-kpi.html).
  4. En Permisos de API → Agregar permiso → Microsoft Graph → Permisos delegados: agregar User.Read, Tasks.Read y User.ReadBasic.All. Pedir a un administrador el consentimiento de administrador.
  5. Copiar el Id. de aplicación (cliente) y el Id. de directorio (inquilino) de la página Información general y pegarlos aquí. Quedan guardados en este navegador.

También puedes pasar la configuración en la URL: planner-kpi.html?clientId=…&tenant=…&plan=Periferia%20Urbana — útil para la pestaña de Teams, así nadie tiene que configurar nada.

¿Cómo lo dejo publicado en el canal “General Administrativo” y que se actualice solo?
  1. Publicar la página: en GitHub → repositorio finanzas → Settings → Pages → Source: main. La página quedará en https://paolamp91.github.io/finanzas/planner-kpi.html.
  2. Agregarla a Teams: abrir el equipo → canal General Administrativo → botón + (Agregar pestaña) → Sitio web → nombre KPI Planner y pegar la URL de arriba (con ?clientId=…&tenant=… al final).
  3. Actualización: no hay que hacer nada. Cada vez que alguien abre la pestaña, la página consulta Planner en vivo; además se refresca sola cada 5 minutos mientras está abierta. Cada persona inicia sesión con su propia cuenta de Microsoft la primera vez.
